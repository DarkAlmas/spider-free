# «Нить» — HUD v1 (Design mock)
Рабочее название: **«Нить»** (запасное «Вектор»). Оригинальный герой: геометрический костюм teal #14B8A6 + violet #7C3AED.
**IP:** только оригинал — никаких Spider-Man/Marvel/Insomniac/Sony имён, логотипов, красно-синего костюма, паутинного узора.
## Управление (для Programming Bot)
- Mobile: правая кнопка «Нить» — тап = короткий рывок к точке прицела; удержание = качание на нити; отпустить = отцеп (сохраняем импульс).
- Левая кнопка «Прыжок»; левая половина экрана — виртуальный стик; свайп справа — камера.
- ⏸ пауза, 🗺 карта (мини-карта/компас вверху справа).
- PC: WASD, мышь — камера/прицел, ЛКМ держать — нить, Space — прыжок, M — карта, Esc — пауза.
- Шкала «Нить» расходуется на рывки, восстанавливается на земле/крышах.
