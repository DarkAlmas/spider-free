# spider-free

Бесплатный **оригинальный** прототип игры про героя с паутиной-тросом (Godot 4.3). Свой герой «Нить», свой процедурный город.
Это НЕ Marvel / Spider-Man: никаких имён, ассетов и логотипов Marvel не используется.

## Запуск
- **Windows:** скачай `spider-free-windows.zip` из Releases, распакуй, запусти `spider-free.exe`.
- **Linux:** `spider-free.x86_64` из Releases.
- **Из исходников:** открой папку в Godot 4.3 → F5, или `godot --path .`

## Управление
| Клавиша | Действие |
|---|---|
| WASD | ходьба, Shift — бег |
| Мышь | камера |
| Space | прыжок / на тросе — подтянуться |
| ЛКМ | выстрел паутиной (в точку прицела камеры) |
| ПКМ | отпустить (+толчок вверх) |
| R | респаун, Esc — освободить мышь |
